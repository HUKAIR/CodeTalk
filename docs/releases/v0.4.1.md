# CodeTalk 0.4.1

CodeTalk 0.4.1 reads wrapped decision notes in full and turns `codetalk graph`
into a development thread one person can read alone. The PyPI distribution
remains `hukair-codetalk`; installation still provides the `codetalk` command
and `codetalk` Python package.

## Primary Workflow

`Vibe-Decision`, `Vibe-Watch` and `Vibe-Rejected` notes that wrap onto
indented continuation lines are now read in full by `blame`, `search`, `ask`,
`brief` and the console. Previously only the first line was kept. Narratives
cached before this release keep working without being rewritten.

`codetalk graph` draws every scanned commit on a time trunk, with decisions
and the reader's planned directions growing upward and rejected options and
open watches growing downward. Cards carry a one-line summary; clicking a node
or a relation line opens the full text, files, neighbouring commits and, when
served, the commit diff. A marker shows the latest commit, and an understood
count with a "next unread" jump shows how much of the recorded history the
reader has worked through. `codetalk graph --serve` adds local-only notes,
tags, pinned positions, manual links, planned directions and understood marks;
Git history is never written, and the static export stays read-only.

## Integrity

`SHA256SUMS` covers every distributable and the CycloneDX 1.6 SBOM. The SBOM
records the same SHA-256 digest for each Python, MCP, and editor artifact. The
GitHub Release is published only after all assets are attached to its draft;
release immutability then locks the tag and assets and produces a verifiable
release attestation.

## Known Limitations

- **cold-start evidence gaps:** repositories without decision notes or optional
  enrichment initially expose little more than commit subjects; the graph shows
  such commits as a folded run on the trunk.
- **human semantic judgment:** same-file relation lines and planned directions
  are reader aids; they cannot decide whether one change caused another or
  whether a plan was really carried out.
- **provider retention:** remote model retention is controlled by the selected
  provider and remains outside CodeTalk guarantees.
- **unofficial local session formats:** Claude Code, Cursor, and Codex session
  formats can change without notice; parsers degrade to the evidence available.
