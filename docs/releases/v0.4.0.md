# CodeTalk 0.4.0

CodeTalk 0.4.0 adds a zero-LLM verbatim search path over decision breadcrumbs
and full commit text, a conclusion-first session recap with a read-only local
server, and first-run guidance that turns dead-end errors into next steps. The
PyPI distribution remains `hukair-codetalk`; installation still provides the
`codetalk` command and `codetalk` Python package.

## Primary Workflow

CodeTalk reviews a local diff against original decision records before the
change ships, keeping authored evidence, generated interpretation, provenance
precision, and maintainer judgment separate.

`codetalk search` now answers from three fixed-order source tiers: verbatim
breadcrumb lines (`Vibe-Decision`/`Vibe-Watch`/`Vibe-Rejected`), verbatim
commit text, and LLM-generated narrative last. The first two tiers need no
cache, key, or prior `digest` run. `codetalk recap` renders a session index
plus per-session detail pages, and `recap --serve` serves both read-only with
on-request recomputation; serve mode never writes to the vault. Bare
`codetalk` prints starter commands instead of an argparse error, and empty
states for `review` and missing session directories explain the cause and
point to a working next command.

## Integrity

`SHA256SUMS` covers every distributable and the CycloneDX 1.6 SBOM. The SBOM
records the same SHA-256 digest for each Python, MCP, and editor artifact. The
GitHub Release is published only after all assets are attached to its draft;
release immutability then locks the tag and assets and produces a verifiable
release attestation.

## Known Limitations

- **cold-start evidence gaps:** repositories without decision notes or optional
  enrichment initially expose little more than commit subjects; verbatim search
  can only surface what commit messages actually contain.
- **human semantic judgment:** deterministic associations can surface relevant
  history but cannot decide whether a current change truly repeats it.
- **provider retention:** remote model retention is controlled by the selected
  provider and remains outside CodeTalk guarantees.
- **unofficial local session formats:** Claude Code, Cursor, and Codex session
  formats can change without notice; parsers degrade to the evidence available.
